# IS-F04: Assessment PREPARING Status Returns Empty Questions

**Status:** ✅ Fixed
**Severity:** 🔴 Critical
**Source:** AUDIT_REPORT.md #4
**Fixed:** May 2026

## Issue
When assessment is in `PREPARING` status (questions being generated by worker), the candidate-facing assessment fetch returned 0 questions with no explanation.

## Fix
`GET /api/assessments/[token]` now returns `{ status: 'preparing', message: 'Your assessment is still being prepared...' }` with metadata when status is `PREPARING`. Candidates see a proper waiting message instead of an empty assessment.
